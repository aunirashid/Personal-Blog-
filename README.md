# Personal Blog Portfolio Website

## Overview

This project is a personal blog portfolio website developed using HTML, CSS, and JavaScript. The website as a digital portfolio that introduces my background, academic journey, projects, and contact information.

The purpose of this project is to showcase my web development skills while providing a platform to present my personal profile and software development projects.

---

## Features

* Home page with personal introduction
* About Me section
* Projects portfolio section
* Contact page with Email, GitHub, and LinkedIn links
* Responsive design for desktop and mobile devices
* Background music feature
* Clean and modern user interface
